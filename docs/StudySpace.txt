## 🎯 Vue d'ensemble

**StudySpace** est une plateforme de classe virtuelle conçue spécifiquement pour les étudiants qui travaillent ensemble à distance. Elle combine visioconférence légère, tableau blanc collaboratif, éditeur d'équations mathématiques WYSIWYG et gestion automatique de l'historique dans une interface unifiée.

### Pourquoi StudySpace ?

Les étudiants jonglent actuellement entre 3-4 applications différentes :
- **Discord** pour la communication vocale
- **Google Docs** pour les notes
- **WhatsApp** pour partager des fichiers
- **Zoom/Meet** pour la vidéo

StudySpace remplace tout ça par une **expérience unifiée** pensée pour le travail collaboratif étudiant.

---

## 🔍 Problème & Solution

### Problème

Les étudiants qui travaillent à distance font face à :

1. **Fragmentation** : Basculer entre 3-4 apps casse le flow de travail
2. **Désorganisation** : Impossible de retrouver ce qui a été fait lors d'une session précédente
3. **Outils inadaptés** : Écrire des équations mathématiques proprement est un calvaire
4. **Coordination difficile** : Partager des fichiers, coordonner la parole, dessiner ensemble = chaos

### Solution

Une plateforme tout-en-un qui :

✅ **Intègre** visio + tableau + notes + fichiers dans une seule interface  
✅ **Organise** automatiquement l'historique en séances chronologiques (comme un cahier de cours)  
✅ **Permet** d'écrire des équations mathématiques visuellement (pas de LaTeX compliqué)  
✅ **Synchronise** tout en temps réel pour tous les participants

## ✨ Fonctionnalités

### Fonctionnalités MVP (v1.0)

#### 🎥 Visioconférence intégrée
- Activation/désactivation cam et micro individuellement
- Vignettes vidéo compactes en haut de l'interface
- Indicateur visuel de qui parle
- Support de 5-10 participants simultanés
- Qualité adaptative selon la connexion

#### 🖼️ Tableau blanc collaboratif
- Dessin libre en temps réel
- Formes simples (rectangle, ellipse, ligne, flèche)
- Zones de texte éditables
- Déplacement et redimensionnement des éléments
- Couleurs et épaisseurs de trait
- Gomme et undo/redo
- Zoom et pan

#### ✏️ Éditeur d'équations WYSIWYG
- Interface visuelle type "Word" pour créer des équations
- Fractions, racines, exposants, indices
- Intégrales, sommes, produits
- Matrices simples
- Insertion dans le tableau blanc ou l'éditeur de texte
- Rendu LaTeX en arrière-plan

#### 📝 Éditeur de texte collaboratif
- Écriture en temps réel
- Mise en forme basique (gras, italique, listes)
- Insertion d'équations depuis l'éditeur WYSIWYG
- Indicateurs de curseur des autres utilisateurs
- Sauvegarde automatique

#### 📁 Gestion de fichiers
- Upload par glisser-déposer
- Formats : PDF, images (JPG, PNG), documents (DOCX)
- Limite : 50 MB par fichier
- Affichage dans panneau latéral

#### 💬 Mini-chat textuel
- Chat simple pour partager liens et infos rapides
- Notifications visuelles discrètes
- Éphémère (disparaît à la fin de la séance)

#### 📅 Système de séances
- Bouton "Commencer une séance" au début du travail
- Timer automatique de durée
- Sauvegarde continue de tout le contenu
- Génération automatique d'une entrée dans l'historique
- Horodatage précis (date + heure + durée)

#### 🗂️ Historique chronologique
- Liste de toutes les séances passées
- Format : "Séance du 18 nov - 2h30"
- Vue détaillée d'une séance (tableau + notes + fichiers)
- Possibilité de reprendre où on s'était arrêté

#### 🏷️ Système de tags
- Tags visuels pour identifier les workspaces (Maths, Info, Physique, etc.)
- 7 tags prédéfinis avec couleurs associées
- Organisation visuelle des espaces de travail

### Base de données (Schéma simplifié)

```prisma
model User {
  id            String      @id @default(uuid())
  email         String      @unique
  passwordHash  String
  name          String
  createdAt     DateTime    @default(now())
  
  workspaces    WorkspaceMember[]
  sessions      Session[]
}

model Workspace {
  id          String      @id @default(uuid())
  name        String
  tag         String      @default("general")
  inviteCode  String      @unique
  createdAt   DateTime    @default(now())
  
  members     WorkspaceMember[]
  sessions    Session[]
  files       File[]
}

model WorkspaceMember {
  id          String      @id @default(uuid())
  role        String      @default("MEMBER") // OWNER | MEMBER
  joinedAt    DateTime    @default(now())
  
  userId      String
  user        User        @relation(...)
  workspaceId String
  workspace   Workspace   @relation(...)
}

model Session {
  id          String      @id @default(uuid())
  startedAt   DateTime    @default(now())
  endedAt     DateTime?
  duration    Int?        // en secondes
  canvasState Json?       // État du canvas
  editorState Json?       // État de l'éditeur
  
  workspaceId String
  workspace   Workspace   @relation(...)
  createdById String
  createdBy   User        @relation(...)
}

model File {
  id          String      @id @default(uuid())
  name        String
  size        Int
  mimeType    String
  url         String
  uploadedAt  DateTime    @default(now())
  
  workspaceId String
  workspace   Workspace   @relation(...)
}
```

JWT_SECRET=your_super_secret_jwt_key_change_this

## 🚢 Déploiement

### Frontend (Vercel)

**1. Connecter GitHub à Vercel**

```bash
# Ou via CLI
vercel

# Suivre les instructions
```

**2. Configuration Vercel**

```
Build Command: cd ../.. && pnpm build --filter=web
Output Directory: apps/web/.next
Install Command: pnpm install
```

**3. Variables d'environnement**

Ajouter dans Vercel Dashboard :
- `NEXT_PUBLIC_API_URL`
- `NEXT_PUBLIC_WS_URL`
- `NEXT_PUBLIC_DAILY_API_KEY` ou `NEXT_PUBLIC_AGORA_APP_ID`

### Backend (Railway)

**1. Créer un nouveau projet**

```bash
# Installer Railway CLI
npm i -g @railway/cli

# Login
railway login

# Init projet
railway init

# Link au projet
railway link
```

**2. Déployer**

```bash
railway up
```

**3. Ajouter les services**

- PostgreSQL (addon Railway)
- Redis (addon Railway)
- Variables d'environnement (comme en local)

### CI/CD (GitHub Actions)

Fichier `.github/workflows/deploy.yml` :

```yaml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy-frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: 20
      - run: pnpm install
      - run: pnpm build --filter=web
      - uses: amondnet/vercel-action@v20
        with:
          vercel-token: ${{ secrets.VERCEL_TOKEN }}
          vercel-org-id: ${{ secrets.ORG_ID }}
          vercel-project-id: ${{ secrets.PROJECT_ID }}

  deploy-backend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - run: railway up
        env:
          RAILWAY_TOKEN: ${{ secrets.RAILWAY_TOKEN }}
```
